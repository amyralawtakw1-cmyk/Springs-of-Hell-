# Clash Arabic News Bot

بوت يقرأ أحدث منشور من RSS، يلخصه بالعربية عبر Gemini، ثم يرسله إلى مجموعة واتساب عبر Green API.

## ما تم تحسينه

- إزالة جميع المفاتيح السرية من الكود واستخدام متغيرات البيئة.
- قاعدة SQLite لمنع إعادة إرسال الخبر بعد إعادة تشغيل الخدمة.
- فحص HTTP صارم واستجابات API قابلة للتحقق.
- حماية من تشغيل مهمتين في الوقت نفسه.
- `GET /health` لمراقبة الخدمة.
- مهلة اتصال واضحة، وUser-Agent، وتنظيف للنص القادم من RSS.
- حماية إضافية من تنفيذ تعليمات مخفية داخل نص الخبر.
- إعدادات قابلة للتغيير دون تعديل الكود.
- تسجيل أخطاء مفيد مع إبقاء الخادم والجدولة يعملان.

## تشغيل محلي

```bash
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# حرر .env وضع المفاتيح الجديدة
python main.py
```

افتح `http://localhost:10000/health` للتحقق من الحالة.

## النشر

- أمر التشغيل: `python main.py`
- اضبط `PORT` من منصة الاستضافة.
- أضف المتغيرات الموجودة في `.env.example` إلى Secrets/Environment Variables في المنصة.
- استخدم خدمة Web Service لا خدمة Job فقط، لأن التطبيق يحتاج منفذاً مفتوحاً.
- اضبط المنطقة الزمنية للخادم أو استخدم وقتاً مناسباً للمنطقة الزمنية المحلية للخادم؛ مكتبة `schedule` تستخدم المنطقة الزمنية المحلية.
- اجعل `DATABASE_PATH` على قرص دائم إن كانت المنصة توفره؛ وإلا سيُفقد سجل التكرار عند إعادة النشر.

## أمان مهم

المفاتيح التي ظهرت في النسخة القديمة يجب اعتبارها مكشوفة: ألغِ/دوّر مفتاح Gemini وGreen API فوراً، ثم ضع القيم الجديدة في Secrets فقط. لا تضع ملف `.env` في GitHub ولا ترسله في المحادثات.

## ملاحظات تشغيلية

- التطبيق يعالج أحدث عنصر فقط في كل تشغيل. هذا مناسب للتشغيل اليومي ويمنع إغراق المجموعة.
- لتجنب التشغيل الفوري عند الإقلاع: `SEND_ON_START=false`.
- لتغيير وقت الإرسال: `RUN_AT=20:00` بصيغة 24 ساعة.
- إذا كان RSS لا يتوفر مؤقتاً، يسجل التطبيق الخطأ ويبقى الخادم متاحاً للمراقبة.
